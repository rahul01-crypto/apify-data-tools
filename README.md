# Apify Data Tools

Small, focused data tools that run on [Apify](https://apify.com). Each one does a single job, and you **pay only per result**: no subscription, no setup, no code. Results can be exported to Excel, CSV or JSON, scheduled to run daily, or called from the Apify API, Make, Zapier, n8n and AI agents.

All tools use public data only (official APIs, public feeds and public web pages) and avoid personal data.

## How to try one

1. Click a tool name above to open it on Apify.
2. Sign in to Apify (free accounts come with monthly free credit).
3. Fill in the input form, or keep the example input, and click **Start**.
4. Download your results as Excel, CSV or JSON.
